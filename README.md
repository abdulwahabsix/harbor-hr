# Harbor HR

Editorial landing page for on-demand HR counsel for service businesses.

**Live site:** https://endearing-lokum-532a6e.netlify.app/

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.

## Deploy

Configured for [Netlify](https://www.netlify.com/) via `netlify.toml`. Pushes to `main` can deploy through Netlify Git integration or the GitHub Actions workflow in `.github/workflows/netlify-deploy.yml`.
